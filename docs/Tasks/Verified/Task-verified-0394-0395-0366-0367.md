## T-0394 — `[ScriviCore]` `scrivi_history_get_tree`

✅ **Verified 2026-08-11** (with SP-092's close — see the recording note below).

Windowed tree retrieval taking `{aroundNodeID?, maxNodes?}`. `scrivi_history_get_tree` **did not
exist** before this task: it was deferred when EP-019 deferred its panel, and the panel then became
EP-030's `history` card. Because the persisted tree already carried every field the card needed
(including `barrierKind` / `barrierNote`), `get_tree` was a **serialization + windowing layer over
existing state**, not new history logic.

**Exit evidence (SP-092):** `scrivi_history_get_tree` returns a windowed tree and `maxNodes` is
honoured (ctest).
